# One Line, Lights Out

Entry for [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) on make.fun.

A single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness lives in one small, exact detail of a machine's life — a cursor blinking at the end of a sentence nobody will finish — stated quietly, not wept over.

> Laptop off. The cursor keeps blinking at the end of a sentence nobody will finish.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+, stdlib only, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, otherwise `/output/entry.txt`, falling back to `./entry.txt`, and exits non-zero if the entry is not 1–200 characters.
